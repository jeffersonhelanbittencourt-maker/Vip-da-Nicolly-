Política de privacidade

Esta versão demonstrativa armazena dados de cadastro e sessão apenas no armazenamento local do navegador utilizado. Esses dados não são enviados a um servidor por este protótipo.

Não utilize dados pessoais reais nesta demonstração. Ao limpar os dados do navegador, os registros locais podem ser apagados.

O pagamento ocorre em plataforma externa. Consulte as políticas do provedor de pagamento para informações sobre os dados tratados por ele.

Uma versão de produção deverá incluir política completa, base legal, canal de contato e controles compatíveis com a LGPD.
