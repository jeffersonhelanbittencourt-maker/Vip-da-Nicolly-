# VIP da Nicolly

Todos os arquivos ficam na mesma pasta (raiz do repositório), sem subpastas.

- `index.html` — página principal
- `admin.html`, `admin.css`, `admin.js` — painel de administradores
- `style.css`, `main.js` — estilo e efeitos do site
- `content.json` — textos, preços e links editáveis
- `banner.jpg` e `perfil.jpg` — imagens (enviadas pelo painel Admin)
- `favicon.svg`, `404.html`, `termos.html`, `privacidade.html`, `robots.txt`

## Publicar
Envie todos os arquivos para o repositório. Em Settings → Pages: Deploy from a branch → `main` → `/ (root)`.
