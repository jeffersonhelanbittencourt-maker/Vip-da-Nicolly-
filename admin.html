Como criar o token (passo a passo)

  1. Entre no GitHub → foto do perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em Repository access escolha Only select repositories e marque só o repositório do site.
  3. Em Permissions → Repository permissions coloque Contents: Read and write.
  4. Gere, copie o token e cole acima. Quem for administrar precisa do próprio token (ou você gera um para ela).
